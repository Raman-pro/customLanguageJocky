# Research & Reference Codebases

This directory contains external reference codebases studied during the reverse engineering and evasion research phase of the **JOCKY** project.

---

## Repositories

| Directory | Description |
|---|---|
| [`Conti-RW-NEW/`](./Conti-RW-NEW/) | Leaked Conti ransomware source code (builder, decryptor, locker). Analyzed for evasion mechanisms, thread pools, and Windows API usage patterns. |
